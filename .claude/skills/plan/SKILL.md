Plan mode. Make no code edits yet.

Use the exploration and the answers to your questions. Write a detailed plan.
Include:

- **Source code changes**: files to add, modify or remove.
- **Documentation updates**: a new ADR for each design decision. A changelog
  entry for each public API change.
- **Change breakdown**: one logical unit per step. Each step keeps `main`
  green. Sessions that commit use `<emoji> <message> (<#issue>)`. See "Git &
  Version Control" in CLAUDE.md.
